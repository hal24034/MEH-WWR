What is an ICE project?

And ICE project (In Class Exercise) is a project that we did in class that took about an hour. It is generally advised to not spend more than that much time on the projects. We do them in class frequently to test and strngthen our knowlage on things we did thought the week. We have also done multiweek projects like this one or the WWR (White Water Rafting) Project.
